# Changelog

## [1.0.1] - 2026-09-28

- Organize package documentation, preserve API and migration examples, and add Stackline community links.
- Improve package discovery keywords with precise domain terms and `stackline`.
- Pin GitHub Actions release tooling and require an explicit missing-version response before publication.


## 1.0.0 - 2026-08-30

- Preserve the `esprima@4.0.1` parser, tokenizer, syntax table, browser,
  CommonJS, AMD, and command-line contracts.
- Replace the historical build and test dependency graph with maintained,
  exact-pinned tooling and a reproducible ES5 distribution build.
- Remove every production, optional, and peer dependency edge.
- Add differential, hostile-key, malformed-input, process-deadline, packed
  consumer, browser, CLI, and runtime compatibility checks.
- Add first-party TypeScript declarations validated with TypeScript 3.9 and
  the current compiler.

The complete upstream release history is retained in [ChangeLog](./ChangeLog).
